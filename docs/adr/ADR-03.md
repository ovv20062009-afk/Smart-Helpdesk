# ADR-03: Модульный монолит

- Статус: принято.
- Контекст: Учебный сервис небольшой, модель работает на CPU.
- Альтернативы: Один модульный сервис; несколько микросервисов.
- Решение: FastAPI в одном Docker-контейнере, модули API, ML, правил и аудита разделены.
- Обоснование: Меньше настроек и сетевых вызовов, проще локальная отладка.
- Последствия: Компоненты масштабируются вместе. При росте нагрузки модель можно вынести отдельно.
