# ADR-02: Модели вне Git

- Статус: принято.
- Контекст: Обученная модель и векторизатор должны иметь согласованные версии.
- Альтернативы: Веса в Git; отдельное хранилище MinIO/MLflow.
- Решение: Хранить pipeline в MinIO/MLflow, а код, метаданные, контрольную сумму и DVC-указатели в Git.
- Обоснование: Бинарные артефакты не увеличивают историю Git. Версия позволяет воспроизвести прогноз.
- Последствия: Нужно отдельное хранилище и проверка доверенного источника; в ЛР 2 используется заглушка.
