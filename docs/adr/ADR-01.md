# ADR-01: Синхронный REST

- Статус: принято.
- Контекст: Клиент отправляет одно небольшое обращение и ожидает маршрут.
- Альтернативы: REST; очередь сообщений с отдельным обработчиком.
- Решение: POST /api/v1/predict возвращает результат сразу.
- Обоснование: Для коротких текстов на CPU достаточно одного HTTP-запроса.
- Последствия: Простая проверка и интеграция; для массовой обработки понадобится очередь.
